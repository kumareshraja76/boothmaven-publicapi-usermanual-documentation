# BoothMaven — Official Mintlify Documentation

This repository contains the complete **BoothMaven Documentation Site** configured for [Mintlify](https://mintlify.com).

## 🚀 Quick Start (Local Preview)

To preview these docs locally on your machine:

1. Install the Mintlify CLI globally:
   ```bash
   npm install -g mintlify
   ```

2. Run the development server from this folder:
   ```bash
   mintlify dev
   ```

3. Open your browser at **`http://localhost:3000`**.

---

## 🌐 Deploying to Mintlify Cloud (Free & Instant)

1. Push this folder to a GitHub repository (e.g. `github.com/your-org/boothmaven-docs`).
2. Go to **[dashboard.mintlify.com](https://dashboard.mintlify.com)**.
3. Click **Add Repository** and select your GitHub repo.
4. Mintlify will automatically build and deploy your docs live with instant search, dark mode, and versioning!
