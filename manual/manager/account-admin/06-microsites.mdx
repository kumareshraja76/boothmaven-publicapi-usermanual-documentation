## Chapter 6: Microsites

Microsites are interactive landing pages created within BoothMaven and shared with leads via URL or QR code. They can include videos, contact forms, product showcases, and booking links. Managed under **My Pages → Microsites**.

### 6.1 The Microsites Library

Lists all pages with name, status (Draft or Published), associated event, and quick actions. Filter by event.

![Microsites library — all interactive landing pages with status and event tags](/manual/manager/images/img_16.png)

*▲ Microsites library — all interactive landing pages with status and event tags*

### 6.2 Creating a Microsite

Click **Create Page**. Give the page a title, choose a template or start from a blank canvas, and add content sections: text blocks, image galleries, video embeds, contact forms, product cards, and call-to-action buttons.

![Create Microsite — builder with template selection and content block options](/manual/manager/images/img_17.png)

*▲ Create Microsite — builder with template selection and content block options*

### 6.3 Editing & Publishing

Click **Edit** on any microsite to return to the builder. When ready, toggle to **Published**. A unique URL and QR code are generated automatically — share the URL in emails, or let staff share it from the Mobile App's Share section.

![Edit Microsite — modify content and layout; toggle between Draft and Published](/manual/manager/images/img_18.png)

*▲ Edit Microsite — modify content and layout; toggle between Draft and Published*

<Tip>
Create a dedicated Microsite for each event. Personalise it with the event name and booth number so recipients immediately recognise the context.
</Tip>
